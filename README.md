# 秘書（Hisyo）

ケアラボ・Dr.Assistant・メディノートの営業/マーケティング、note小説「ヒト、という実験」の執筆支援、
週次のビジネスリサーチを半自動化する、個人用ダッシュボードです。

## 構成

- `/` : ホーム（今日のおすすめタスク）
- `/medical` : 医療系3アプリのX/Threads投稿・note記事生成
- `/character` : 「子だくさんナース」X投稿生成（精神科現場・育児・豆知識・当事者への4カテゴリ）
- `/novel` : 小説の続き執筆・宣伝文・章まとめ・note用サムネイルプロンプト生成
- `/research` : Web検索を使った週次ビジネスリサーチ

生成結果は端末のブラウザ内（localStorage）に保存されます。外部データベースは使っていません。

## Vercelへのデプロイ手順

1. このリポジトリをVercelにインポートする
2. Vercelの Settings → Environment Variables で以下を設定する：
   - `ANTHROPIC_API_KEY`：AnthropicのAPIキー
   - `DASHBOARD_PASSWORD`：このダッシュボードを開くときに入力する、自分専用のパスワード（他人に見られたくないので必ず設定してください）
3. Deploy を押す

## 使い方

- 初回アクセス時にパスワードを聞かれます（`DASHBOARD_PASSWORD`に設定した値）
- 各ページでボタンを押すと生成され、結果はそのままコピーして使えます
- 履歴の「⭐」は「これは良かった」の印です。次回以降の生成で、好評だったテイストを参考にするようになります

## 小説の設定を更新したいとき

`lib/prompts.ts` の `NOVEL_BIBLE` と `NOVEL_SAMPLES` を書き換えてください。
新しいシリーズが増えたら、`NOVEL_BIBLE` の「既出の悪役職業」リストに追記しておくと、
職業の重複を防げます。

## 「子だくさんナース」の投稿トーンを更新したいとき

`lib/prompts.ts` の `CHARACTER_BIBLE` と `CHARACTER_SAMPLES` を書き換えてください。
特に `CHARACTER_SAMPLES` は、実際に良かった投稿を定期的に入れ替えると、生成の精度が保てます。

## 注意点

- Web検索を使うリサーチ機能（`/research`）は、他の生成より時間がかかります（最大90秒）
- 1人用の設計のため、認証はごく簡易的なパスワードのみです。パスワードは他人と共有しないでください
